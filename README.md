# H3 Studio

Generate, edit and export AI video on your own computer.

## Download

Grab the latest version from **[Releases](https://github.com/ekram21/h3-studio-releases/releases/latest)**:

| Your computer | File |
| --- | --- |
| Mac with Apple silicon (M1 and later) | `H3-Studio-<version>-arm64.dmg` |
| Mac with Intel | `H3-Studio-<version>-x64.dmg` |
| Windows | `H3-Studio-<version>-x64.exe` |
| Linux | `H3-Studio-<version>-x86_64.AppImage` |

Already installed? H3 Studio updates itself — you'll see **Update ready** in the sidebar when a new version is downloaded.
