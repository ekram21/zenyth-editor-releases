# Zenyth Editor

AI video, directed and edited in one place, on your own computer.

**Website:** https://zenyth-editor.web.app

## Download

Grab the latest version from **[Releases](https://github.com/ekram21/zenyth-editor-releases/releases/latest)**:

| Your computer | File |
| --- | --- |
| Mac with Apple silicon (M1 and later) | `Zenyth-Editor-<version>-arm64.dmg` |
| Mac with Intel | `Zenyth-Editor-<version>-x64.dmg` |
| Windows | `Zenyth-Editor-<version>-x64.exe` |
| Linux | `Zenyth-Editor-<version>-x86_64.AppImage` |

Already installed? Zenyth Editor updates itself. You'll see **Update ready** in the sidebar when a new version is downloaded.
